1. Introduction

Welcome to Hive API Client ("we", "us", "our", or "Company"). We are committed to protecting your privacy. This Privacy Policy explains our practices regarding data collection, usage, and protection for our Chrome extension.

We believe in transparency and user control. Your privacy is paramount, and we've designed Hive API Client with privacy-first principles.

2. Data We Collect

Hive API Client operates with minimal data collection. Here's what we collect and why:

Request Data

API endpoints, headers, parameters, and request bodies you create are stored locally on your device only. This data is never transmitted to external servers.

Collections

Organized groups of your saved requests are stored locally in your browser's storage, allowing you to organize and reuse requests efficiently.

Environment Variables

Configuration data for different environments (dev, staging, prod) that you create are stored locally for seamless environment switching.

User Preferences

Theme selection (dark/light mode) and other UI preferences are stored to provide a personalized experience.

Request History

A log of requests you've made is stored locally for your convenience and quick access to frequently used endpoints.

🔒 Important: All of this data remains exclusively on your device. We never collect, transmit, or store any of this data on our servers.

3. How We Use Your Data

All data collection serves specific purposes to enhance your experience:

  • To enable you to test and debug APIs
  • To save your requests and collections for future use
  • To maintain your request history
  • To preserve your preferences and settings
  • To provide a seamless multi-session experience
  • To improve the extension's performance and functionality

We do not: Sell, rent, or share your data with third parties. We do not use your data for marketing, profiling, or any purpose other than providing you with Hive API Client's core functionality.

4. Local Storage Only

Your data never leaves your device. This is a core principle of Hive API Client:

  • ✅ Stores all data locally using Chrome's storage API
  • ✅ Does not send your requests or data to any external server
  • ✅ Does not use cloud synchronization
  • ✅ Does not share data with third parties
  • ✅ Does not use analytics or tracking tools
  • ✅ Does not collect personal information

💡 Pro Tip: You have complete control over your data. Uninstall the extension at any time to completely remove all stored data, or manually delete individual requests and collections within the extension.

5. Permissions Explained

Hive API Client requires specific Chrome permissions. Here's what each permission is used for and why it's necessary:

🗄️ Storage Permission

Allows us to save your requests, collections, environments, preferences, and history locally on your device using Chrome's storage API. This enables persistence across browser sessions so you don't lose your work.

📑 Tabs Permission

Allows us to access information about open tabs to integrate with your browser and provide context-aware features. We use this to coordinate extension features with your browsing context.

🌐 Host Permissions (All URLs)

Allows us to send HTTP requests to any API endpoint you specify. This permission is essential for API testing functionality—you need to be able to send requests to any domain, localhost servers, or internal APIs without restrictions.

Why we need these: Chrome's security model requires us to declare these permissions upfront. We only use each permission for its stated purpose.

6. Data Security

We implement multiple security measures to protect your data:

  • Local Storage: All data remains on your local device, eliminating transmission risks
  • No Network Transmission: Your request data is never sent over the internet to our servers (only to the API endpoints you specify)
  • Chrome Security Sandbox: Chrome's built-in security sandbox protects extension execution
  • Content Security Policy: We implement strict CSP headers to prevent injection attacks
  • Transparent Code: Code is available for inspection and community review
  • No External Requests: The extension doesn't make background requests to tracking or analytics services

7. Data Retention

Your data is retained based on your choices:

  • While Using: Data persists as long as the extension is installed and active
  • Manual Deletion: You can delete individual requests, collections, or all data at any time through the extension interface
  • Complete Removal: Uninstalling the extension removes all stored data
  • Browser Data Clearing: Clearing your browser's stored data or extension data will remove all Hive API Client information

You maintain complete control over when your data is deleted. We don't automatically delete your data without your action.

8. Third-Party Services

Hive API Client does not integrate with third-party services for data collection or analytics.

External resources we use (with no data sharing):

  • Google Fonts: For typography styling. This is loaded from Google's CDN but no personal data is shared—only standard HTTP requests

We explicitly do NOT use:

  • Analytics tools (Google Analytics, Mixpanel, etc.)
  • Crash reporting services
  • Error tracking tools
  • Session recording software
  • Data brokers or marketing platforms

9. Children's Privacy

Hive API Client is designed for developers and technical professionals and is not intended for children under 13.

We do not knowingly collect information from children under 13. If we become aware that we have collected personal information from a child under 13, we will delete such information and terminate the child's account immediately.

Parents or guardians who believe their child has provided information to Hive API Client should contact us immediately.
