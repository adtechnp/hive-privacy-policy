Privacy Policy

Last Updated: April 2026

Introduction

Welcome to Hive API Client ("we", "us", "our", or "Company"). We are committed to protecting your privacy. This Privacy Policy explains our practices regarding data collection, usage, and protection for our Chrome extension.

1. Data We Collect

Hive API Client operates with minimal data collection. Here's what we collect and why:

  • Request Data: API endpoints, headers, parameters, and request bodies you create. This data is stored locally on your device only.
  • Collections: Organized groups of your saved requests, stored locally in your browser's storage.
  • Environment Variables: Configuration data for different environments (dev, staging, prod) that you create.
  • User Preferences: Theme selection (dark/light mode) and other UI preferences.
  • Request History: A log of requests you've made, stored locally for your convenience.

2. How We Use Your Data

All data collection serves specific purposes to enhance your experience:

  • To enable you to test and debug APIs
  • To save your requests and collections for future use
  • To maintain your request history
  • To preserve your preferences and settings
  • To provide a seamless multi-session experience

3. Local Storage Only

Your data never leaves your device. Hive API Client:

  • Stores all data locally using Chrome's storage API
  • Does not send your requests or data to any external server
  • Does not use cloud synchronization
  • Does not share data with third parties
  • Does not use analytics or tracking tools
  • Does not collect personal information

4. Permissions Explained

Hive API Client requires specific Chrome permissions. Here's what each permission is used for:

  • Storage Permission: To save your requests, collections, environments, preferences, and history locally on your device.
  • Tabs Permission: To integrate with your browser and access information about open tabs for context-aware features.
  • Host Permissions (All URLs): To send HTTP requests to any API endpoint you specify, enabling API testing across any domain or localhost.

5. Data Security

We implement several security measures to protect your data:

  • All data remains on your local device
  • No transmission over the internet of your request data
  • Chrome's built-in security sandbox protects extension execution
  • Code is open to inspection and community review

6. Data Retention

Your data is retained as long as:

  • You keep the extension installed
  • You don't clear your browser's stored data
  • You choose to keep your requests and collections

You can delete all your data at any time by uninstalling the extension or manually clearing your stored requests.

7. Third-Party Services

Hive API Client does not integrate with third-party services for data collection or analytics. The only external resources we use are:

  • Google Fonts (for typography) - no data is shared with Google

8. Children's Privacy

Hive API Client is not intended for children under 13. We do not knowingly collect information from children under 13. If we become aware that we have collected personal information from a child under 13, we will delete such information and terminate the child's account.

9. Changes to This Privacy Policy

We may update this Privacy Policy from time to time to reflect changes in our practices or for other operational, legal, or regulatory reasons. We will notify you of any material changes by updating the "Last Updated" date and posting the new policy.

10. Contact Us

  • Email: support@hiveapi.local
  • GitHub: [Your GitHub Repository]

11. Your Rights

You have the right to:

  • Access all your stored data at any time through the extension
  • Delete your data by uninstalling the extension
  • Manually delete individual requests or collections
  • Export your data if we provide that functionality

12. Compliance

Hive API Client complies with:

  • Chrome Web Store Developer Program Policies
  • GDPR (General Data Protection Regulation) - by not collecting personal data
  • CCPA (California Consumer Privacy Act) - by maintaining local-only storage

By using Hive API Client, you acknowledge that you have read and understood this Privacy Policy.
